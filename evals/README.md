# evals

**Agent quality evaluations: datasets of cases (`G-xx`), deterministic graders, model-graded rubrics, and stored results compared with a baseline. Added with the first prompt that matters (Phase 2, post drafting).**

- Runs on demand and on every prompt or model change; calls real models, so it is separate from unit tests (conventions §15.10).
- Reports are written to `evals/reports/` (git-ignored) and summarised in the PR.
